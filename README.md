# 조립메이트 — 용도별 PC 부품 추천과 가격 검색

## 실행
`index.html`을 최신 브라우저에서 열면 사용할 수 있습니다. 빌드, 패키지 설치, 계정은 필요하지 않습니다. 구성 가격은 참고 예산이며 실시간 상품 정보를 자동으로 수집하지 않습니다.

## 핵심 기능
1. **기초 용도 안내** — 문서·인터넷, 게임, 영상·디자인 등 주 용도와 PC 선택 순서를 쉽게 설명합니다.
2. **가격 확인** — 추천 부품마다 다나와, 네이버 쇼핑, 쿠팡, G마켓 검색 링크를 제공합니다. 검색 결과에서 현재가, 배송비, 재고, 카드 조건 및 정확한 상품 모델을 확인합니다.
3. **용도별 부품 추천** — 각 용도에 대해 예산 단계별 CPU, 메인보드, 메모리, SSD, 그래픽, 파워, 케이스/냉각 구성 예시를 표시하고, 각 부품마다 추천 이유를 간략히 설명합니다. 설명은 해당 용도에서 부품이 담당하는 역할과 구성상 고려점을 안내하는 것이며, 특정 상품의 성능을 보증하지 않습니다.
4. **희망 예산 입력** — 30만~1,000만 원 범위에서 1만 원 단위로 입력할 수 있습니다. 선택한 PC 용도의 가격 범위와 대조해 가장 가까운 추천 구성을 선택하고 예산 금액을 표시합니다. 개별 부품 실시간가를 합산하는 견적 기능은 아닙니다.
5. **읽기 쉬운 글자** — 본문 및 동적으로 표시되는 용도, 구성, 부품 안내 글자를 기본 스타일보다 약 50% 크게 표시합니다.

## 추천 이유가 뜻하는 것
추천 이유는 예를 들어 내장 그래픽 CPU가 사무용에서 별도 그래픽카드 비용을 줄여주는 점, 게임 구성에서 GPU와 메모리 용량을 고려한 점, 저장장치 용량이 용도에 맞는 점을 짧게 풀이합니다. 이는 정량 벤치마크 비교나 실시간 가격 조사 결과가 아니며, 제품 세대·가격·사용 프로그램에 따라 적합성이 달라질 수 있습니다.

## 가격 및 구매 전 주의
- 페이지의 가격은 대략적인 **예상 본체 예산 범위**입니다. 실시간 가격 피드나 보장 가격이 아닙니다.
- 검색 링크는 부품명으로 다나와/네이버 쇼핑/쿠팡/G마켓 검색 결과를 엽니다. 비슷한 이름의 제품이 많으므로 세부 모델, 신품/중고, 판매처 신뢰도, 배송비, 쿠폰/카드 조건과 재고를 직접 대조하세요.
- 구성은 가이드이지 맞춤 견적 보증이 아닙니다. 케이스의 그래픽카드 길이, 쿨러/라디에이터 간섭, 메인보드 CPU 소켓·BIOS·메모리 지원, 파워 용량 및 그래픽카드 전원 커넥터를 **정확한 상품 모델 기준**으로 확인해야 합니다.
- 모니터, 운영체제, 조립비, 배송비, 키보드/마우스, 추가 저장장치는 예산에 포함되지 않습니다. 보드에 따라 Wi-Fi·블루투스도 달라집니다.
- 부품 세대와 재고·가격은 변합니다. 구매 시점에 제조사 사양과 판매처 정보를 다시 확인하세요. 특히 오래된/단종 CPU·GPU가 예시에 포함될 수 있습니다.

## 접근성 및 실제 시험
키보드로 용도와 구성 카드를 선택할 수 있고, 현재 선택은 `aria-pressed`로 전달됩니다. 선택이 바뀌면 화면 읽기 프로그램에 선택과 예산을 알립니다. 축소 동작 설정과 모바일 화면을 지원하도록 구성했습니다. 실제 브라우저와 보조기술별 시험은 이 작업에서 수행하지 않았습니다.

## 현재 범위와 다음 개선
현재 가격을 앱 안에서 직접 자동 수집하는 기능은 구현되지 않았습니다. 판매처의 실시간 API 연동, 정확한 SKU 단위 호환성 검사, 부품별 실시간 가격 합계, 가격 업데이트 시각은 추가 개발이 필요합니다. 외부 검색 링크는 최신 가격을 사용자가 판매처에서 확인하도록 연결합니다.

사용자가 실제로 부품을 주문하기 전에 정확한 상품 모델과 전체 견적을 다시 검증하도록 안내합니다. 구성 단계의 가격 범위와 입력 예산만으로 구매 결정을 내리지 마세요.

## 주요 파일
- `index.html` — 웹 앱의 구조와 화면 문구
- `styles.css` — 기본 반응형 레이아웃과 스타일
- `app.js` — 용도/구성 데이터, 추천 UI 및 기본 검색 링크
- `enhancements.css` — 희망 예산과 추가 판매처 링크 레이아웃
- `enhancements.js` — 글자 확대, 만 원 단위 예산 선택, 추가 검색 링크
- `README.md` — 실행과 기능, 가격/호환성 한계
- `plan.md` — 목적, 현재 구현 범위 및 후속 계획

브라우저를 실행할 수 있는 도구가 없어 이 작업에서는 실제 브라우저 시험을 수행하지 않았습니다.
